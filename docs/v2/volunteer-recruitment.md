# ชุดเริ่มเก็บข้อมูลภาคสนาม — ชวนเกษตรกรอาสา + ขอเจ้าหน้าที่สำรวจพืช (ฉบับ 10 พ.ย. 2569)

ทำไมสำคัญที่สุดตอนนี้: production ณ 10 พ.ย. มี **คำตอบอาสา 0 · label พืช 0** — ตัวเลขความแม่นยำที่จะรายงานผู้ให้ทุน
และโมเดลทายชนิดพืช รอข้อมูลชุดนี้ทั้งหมด ระบบพร้อมรับแล้ว (deploy แล้ว) เหลือแค่ชวนคนมาใช้

คุณเป็นผู้ส่งข้อความเอง · แก้ช่อง ____ ก่อนส่ง · ชื่อปุ่มในเอกสารนี้ตรงกับแอปจริง (ตรวจจากโค้ด 10 พ.ย.)

## 1. เป้าหมายรอบแรก (ระดับ "เริ่มต้น" ใน [success-criteria-draft.md](success-criteria-draft.md))

| อะไร | เป้า | ดูความคืบหน้าที่ |
|---|---|---|
| เกษตรกรอาสา | 8–10 ราย | `/dashboard/validation.html` (ผู้ตอบ) |
| จุดที่ระบบชี้ ที่ตอบ จริง/ไม่จริง | ≥ 50 จุด | `/dashboard/validation.html` (precision) |
| จุดสุ่ม (🎲) ที่ตอบแล้ว | อาสาละ 5 จุดต่อแปลง | `/dashboard/validation.html` (recall) |
| จุดสำรวจพืชของเจ้าหน้าที่ | พืชละ ≥ 10 จุด ใน 2–3 อำเภอ (รวม ≥ 50 แปลง) | `/dashboard/crop-model.html` |

ตัวเลขเป้าเป็นข้อเสนอ ปรับได้ · recall ต้องเก็บช่วงที่มีฝน — ถ้าแล้งมากจะมีจุดน้ำขังจริงน้อย

## 2. ข้อความชวนเกษตรกรอาสา (LINE — ส่งรายบุคคลหรือในกลุ่ม)

```
สวัสดีครับ ผม ____ จากโครงการ IAM ROOT (แอปใน LINE ที่ใช้ภาพดาวเทียมชี้จุดชื้น/จุดเสี่ยงน้ำขังในสวนทุเรียน) 🌳

กำลังหาเกษตรกรอาสา ____ ราย ช่วยตรวจว่าแอปชี้จุดได้ตรงกับในสวนจริงไหมครับ
• ใช้เวลาประมาณ 20–30 นาทีต่อแปลง เดินไปดูตามจุดที่แอปบอก แล้วกดตอบ "จริง / ไม่จริง / ไม่แน่ใจ"
• ไม่มีค่าใช้จ่าย ไม่ต้องติดตั้งอะไรเพิ่ม ใช้ใน LINE ได้เลย
• ไม่บังคับ ถอนตัวได้ทุกเมื่อ คำตอบใช้วัดความแม่นยำของระบบเป็นตัวเลขรวม ไม่ระบุชื่อคุณ

สนใจตอบกลับ "สนใจ" ได้เลยครับ เดี๋ยวส่งวิธีใช้ให้ 🙏
เปิดแอป: ____ (ลิงก์ LINE OA / LIFF)
```

## 3. วิธีใช้สำหรับอาสา (ส่งต่อหลังตอบ "สนใจ")

```
วิธีช่วยตรวจ (ทำครั้งเดียว ข้อ 1–2)
1) เปิดแอป IAM ROOT ใน LINE → เมนู "⚙️ ข้อมูลของฉัน" → ติ๊ก "เข้าร่วมทดสอบระบบเป็นเกษตรกรอาสา" → กด "💾 บันทึกความยินยอม"
   (ถ้าแอปขึ้นหน้า "ก่อนใช้งาน IAM ROOT" ติ๊กข้อนี้ได้ในหน้านั้นเลย แล้วกด "ยอมรับและใช้งานต่อ")
2) ถ้ายังไม่มีแปลง: วาดขอบเขตสวนของคุณในแอป แล้วรอผลตรวจแปลง

ทุกครั้งที่เข้าสวน
3) เปิดแปลง ให้แผนที่จุดขึ้น → แตะจุดสีที่แอปชี้ → เดินไปดูจริง → ตอบ
   "ไปดูที่จุดนี้แล้ว เป็นแบบนี้จริงไหม?"  ✅ จริง / ❌ ไม่จริง / 🤔 ไม่แน่ใจ
   และ "🌳 ต้นไม้ตรงจุดนี้มีอาการผิดปกติไหม?"  ✅ มี / ❌ ไม่มี / 🤔 ไม่แน่ใจ
   แนบรูปได้ที่ "📷 แนบรูปจุดนี้"
4) สำคัญมาก: ใต้สรุปแปลงกด "🎲 สุ่มจุดให้ตรวจ" → แอปสุ่ม 5 จุดที่ "ไม่ได้เตือน" (วงสีเขียว)
   → กด "🧭 นำทาง" ไปที่จุด → "ตอบจุดนี้" ว่ามีน้ำขัง/ดินแฉะไหม
   จุดชุดเดิมจะคงอยู่ 14 วัน ตอบให้ครบ 5 จุด

ข้อสำคัญ: ตอบหลังเดินไปดูจริงเท่านั้น · ไม่แน่ใจให้กด "ไม่แน่ใจ" ดีกว่าเดา · ไม่ต้องเลือกจุดเอง ใช้จุดที่แอปสุ่มให้
```

หมายเหตุสำหรับคุณ:
- สวน**ยกร่อง**ไม่มีปุ่ม 🎲 (ระบบไม่สุ่มในสวนยกร่อง) — ชวนอาสาที่เป็นสวนพื้นราบก่อน
- ทำไมต้องจุดสุ่ม: ถ้าอาสาเลือกจุดเอง ระบบจะดูเหมือนพลาดน้อยกว่าความจริง → recall ใช้เฉพาะจุดสุ่ม
- ข้อยินยอม "เกษตรกรอาสา" ยังใช้ร่างนโยบายที่ **ยังไม่ผ่านผู้รู้ PDPA** — ถ้าจะรายงานผู้ให้ทุนเป็นทางการ ควรให้ตรวจก่อน

## 4. ข้อความขอเจ้าหน้าที่เกษตรสำรวจพืช (LINE)

ก่อนส่ง: สร้างรหัสเชิญเจ้าหน้าที่ที่ `/dashboard/users.html` → หัวข้อ "สร้างรหัสเชิญเจ้าหน้าที่" เลือกอำเภอที่รับผิดชอบ → "➕ สร้างรหัสเชิญ" (ค่าเริ่มต้น หมดอายุ 14 วัน ใช้ได้ 1 คน) แล้วแนบลิงก์

```
สวัสดีครับ พี่/คุณ ____ ผม ____ จากโครงการ IAM ROOT 🌳

ขอรบกวนช่วยบันทึก "ชนิดพืช" ของสวนที่พี่ลงพื้นที่อยู่แล้วครับ ใช้สอนระบบให้ทายชนิดพืชจากภาพดาวเทียม
• ยืนในแปลง → กดบันทึก → เลือกพืชที่เห็น ใช้เวลาจุดละไม่ถึง 1 นาที ไม่มีสัญญาณก็บันทึกได้
• ไม่ต้องให้เกษตรกรมีบัญชี ไม่บันทึกชื่อเจ้าของ (ขอให้ถามเจ้าของแปลงก่อนบันทึก)
• เป้า: พืชละ 10 จุดขึ้นไป (ทุเรียน มะพร้าวน้ำหอม ฝรั่ง ชมพู่ องุ่น ส้มโอ)

ขั้นตอน
1) กดลิงก์เปิดสิทธิ์เจ้าหน้าที่: ____ (เปิดใน LINE)
2) แท็บ "👩‍🌾 พื้นที่ของฉัน" → "📍 สำรวจจุดนี้"
3) ยืนในแปลงเดียว ห่างขอบ 20 เมตรขึ้นไป รอจนขึ้น "✅ ตำแหน่งแม่นพอแล้ว"
4) เลือกพืช → ติ๊ก "เจ้าของแปลงอนุญาต…" → "💾 บันทึกจุดสำรวจ"

คู่มือเต็ม: ____ (แนบ docs/v2/officer-guide.md ข้อ 9)
ขอบคุณมากครับ 🙏
```

## 5. ติดตามรายสัปดาห์ (ผู้ดูแล)

1. `/dashboard/validation.html` — จำนวนผู้ตอบ, จุดที่ระบบชี้ที่ตอบชัด, จุดสุ่มที่ตอบ
2. `/dashboard/crop-model.html` — label ต่อชนิดพืช / จำนวนอำเภอ เทียบเกณฑ์ (≥ 50 แปลง, ≥ 10 ต่อชนิด, ≥ 3 กลุ่ม)
3. ครบเกณฑ์แล้วพิมพ์ "ทำต่อ" ให้ Claude → คำนวณความแม่นยำพร้อมช่วงความเชื่อมั่น / เทรนโมเดลพืช
