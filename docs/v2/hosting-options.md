# ทางเลือก hosting (เขียนเมื่อ Render ระงับบริการเรื่องค่าใช้จ่าย — 30 ต.ค. 2569)

ผู้อ่าน: เจ้าของโปรเจกต์ · **ยังไม่ย้ายอะไร** — ย้ายระบบต้องให้เจ้าของเลือกก่อน (เกี่ยวกับเงิน)

## สถานการณ์

- 29 ต.ค. 2569 14:15 น. Render ระงับ service IAMROOT ด้วยเหตุ **billing** → แอปใน LINE ใช้ไม่ได้, แชทบอทไม่ตอบ,
  สแกนรายวัน/เตือนฝนหยุด · ฐานข้อมูล Supabase ไม่กระทบ · โค้ดไม่มีปัญหา (deploy ล่าสุดสำเร็จ)
- Phase 0 เจ้าของเลือกทาง A = อยู่ Render starter ต่อ (ไม่หลับ) → **ทางที่เร็วที่สุดคือชำระค่าบริการแล้วกด Resume**

|---|---|---|---|---|
| **Render starter (เดิม)** | ~$7 | ไม่หลับ | ไม่มี — แค่ชำระเงิน | 512 MB ใช้อยู่แล้วพอ · ตรวจด้วยว่า workspace ไม่ได้ถูกเก็บค่า Pro ($25) เพิ่ม |

## คำแนะนำ

1. **ตอนนี้: ชำระค่า Render แล้ว Resume** (~$7/เดือน ไม่ต้องแก้อะไร) — แอปกลับมาทันที
2. ถ้าต้องการลดค่าใช้จ่ายระยะยาว: Fly.io ประหยัด ~$3.5/เดือน แต่ต้องย้ายระบบและเปลี่ยน URL ใน LINE Developers
   (มีความเสี่ยงช่วงย้าย) — คุ้มเมื่อรวมกับงานอื่น ไม่ควรทำเพียงเพื่อเหตุการณ์ครั้งนี้
3. ตั้งแจ้งเตือนบัตร/ยอดค้างใน Render Billing และเพิ่มอีเมลผู้รับแจ้งเตือนสำรอง กันระงับซ้ำ
