# แหล่งข้อมูลพยากรณ์ฝน — ตัวเลือกและเงื่อนไข (Phase 3 — 25 ต.ค. 2569)

ผู้อ่าน: เจ้าของโปรเจกต์ · spec 6.1 "เสนอแหล่งข้อมูลพร้อมเงื่อนไขการใช้งาน ให้ผมเลือก" · **ยังไม่ได้เปลี่ยนแหล่งหรือสมัครแพลนใด**

## ตอนนี้ระบบใช้อะไร

`weather_alert.get_7day_rain()`: ลอง **WeatherNext** (Google DeepMind ผ่าน Earth Engine) ก่อน ถ้าใช้ไม่ได้ใช้ **Open-Meteo** (ฟรี ไม่ต้องมี key)
· WeatherNext ต้องได้สิทธิ์เข้าถึงชุดข้อมูล — ตามโค้ดเดิมยังไม่ยืนยันว่าได้ จึงมักใช้ Open-Meteo

## ต้องให้เจ้าของตัดสินใจ

1. **โครงการนี้เป็นเชิงพาณิชย์หรือไม่** (spec ค่าเริ่มต้น: ถือว่าเป็น) — ถ้าใช่ การใช้ Open-Meteo ฟรีต่อไปขัดเงื่อนไข
2. เลือก: **(ก) สมัคร Open-Meteo Standard** (~$29/เดือน ตรวจราคาจริงก่อน) — เปลี่ยนง่ายที่สุด
   / (ข) ติดต่อกรมอุตุฯ ขอ API พยากรณ์รายพิกัด (ฟรี แต่ใช้เวลา) / (ค) ใช้ Open-Meteo ฟรีต่อเฉพาะช่วงนำร่องที่ไม่เก็บเงิน
3. ระหว่างรอ ระบบใช้ Open-Meteo ต่อ และใส่ที่มา "Weather data by Open-Meteo.com" ในข้อความเตือนตามเงื่อนไข CC BY 4.0

**ข้อเสนอ:** ถ้านำร่องร่วมกับเกษตรจังหวัดโดยไม่เก็บเงินเกษตรกร → (ค) ไปก่อน + เริ่มติดต่อกรมอุตุฯ (ข) คู่กัน
ถ้าเริ่มขาย/เก็บเงินเมื่อไร → (ก) ทันที (การจ่ายเงินเป็นการตัดสินใจของเจ้าของ — Claude ไม่สมัครเอง)
