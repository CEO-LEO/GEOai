# สำรวจข้อมูลระดับน้ำ / ความเค็มรุก สำหรับราชบุรี (Phase 3 ข้อ 6.2 — รายงานก่อนทำ)

ผู้อ่าน: เจ้าของโปรเจกต์ · 25 ต.ค. 2569 · **ยังไม่ได้เชื่อมต่อแหล่งใด** (spec ให้สำรวจและรายงานก่อน)

## ทำไมเกี่ยวกับราชบุรี

สวนยกร่องในดำเนินสะดวก/บางแพ/วัดเพลง รับน้ำจากแม่น้ำแม่กลองและคลองชลประทาน — หน้าแล้งมีความเสี่ยง
**น้ำเค็มรุก** จากปากแม่น้ำ และหน้าฝนมี **ระดับน้ำในแม่น้ำ/คลองสูง** ที่ทำให้ร่องสวนระบายน้ำไม่ออก
ข้อมูลดาวเทียมของระบบมองไม่เห็นเรื่องนี้ (ดูได้แค่ความชื้นผิว)

## แหล่งที่พบ

| แหล่ง | มีอะไร | การเข้าถึง | สถานะ |
|---|---|---|---|
| **ThaiWater (สถาบันสารสนเทศทรัพยากรน้ำ — สสน.)** | รวมข้อมูลน้ำและอากาศจากกว่า 50 หน่วยงาน · มีเอกสาร API อ่านข้อมูลสถานีตรวจวัด รวมสถานีคุณภาพน้ำ | API ตามมาตรฐาน ThaiWater — ยังไม่พบเงื่อนไขการใช้/วิธีขอ key ที่เป็นปัจจุบัน | **น่าใช้ที่สุด** — ต้องติดต่อ สสน. |
| **กรมชลประทาน (RID)** | โทรมาตรระดับน้ำ/ความเค็ม (เอกสารที่พบเน้นเจ้าพระยา) · แม่กลองมีการผันน้ำไล่ความเค็ม | ยังไม่พบ API สาธารณะ | ต้องติดต่อโครงการชลประทานราชบุรี |
| **ศูนย์ข้อมูลเปิดภาครัฐ (data.go.th)** | ชุดข้อมูลตรวจวัดแหล่งน้ำ (กรมทรัพยากรน้ำ) ตามมาตรฐาน ThaiWater | ดาวน์โหลดได้ แต่รายการที่พบข้อมูลไม่ครบ ความถี่ไม่ระบุ | ใช้อ้างอิงได้ ยังไม่เหมาะกับเตือนรายวัน |
| ข้อมูลความเค็มแม่กลองเชิงวิจัย (ม.เกษตรศาสตร์) | กราฟความเค็มสูงสุดตามลำน้ำ | หน้าเว็บเก่า ไม่มี API | ใช้เป็นพื้นหลังเท่านั้น |

## ถ้าได้ข้อมูล จะทำอะไรได้

1. แท็บ/การ์ด "ระดับน้ำคลองใกล้สวน" สำหรับสวนยกร่อง (เทียบระดับวิกฤตของสถานีที่หน่วยงานกำหนด — ไม่ตั้งเกณฑ์เอง)
2. เตือนความเค็มรุก (หน้าแล้ง) เมื่อสถานีใกล้แปลงเกินเกณฑ์ที่กรมชลประทานใช้ — ส่งผ่านตัวคุมโควตาเดียวกับเตือนฝน
3. แสดงในแดชบอร์ดจังหวัดรายอำเภอ

## ต้องให้เจ้าของ/เกษตรจังหวัดช่วย

1. ติดต่อ สสน. (ThaiWater) ขอสิทธิ์ใช้ API สถานีระดับน้ำ/คุณภาพน้ำลุ่มแม่กลอง + เงื่อนไขการใช้ในงานกับหน่วยงานรัฐ
2. สอบถามโครงการชลประทานราชบุรี: สถานีวัดความเค็มที่ใช้จริง และเกณฑ์ที่ใช้เตือนเกษตรกร
3. เมื่อได้ API + เกณฑ์ → Claude ทำต่อเป็น Phase 3e (ประมาณ 3–5 วัน) — เกณฑ์ต้องมาจากหน่วยงาน ไม่เดา
