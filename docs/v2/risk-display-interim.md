# ข้อความแสดงระดับความเสี่ยงระหว่างปรับปรุง — ร่างเพื่อขออนุมัติ (ยังไม่ได้แก้หน้าแอป)

วันที่: 2026-10-17 · ใช้ระหว่างรันคู่ 2–4 สัปดาห์ แทนป้าย "เสี่ยงสูง" แบบเดิมที่ผิดเกือบทุกแปลง

## 1. หลักการ
- ไม่แสดงป้าย "เสี่ยงสูง / ปานกลาง / ปกติ" จากวิธีเดิมในหน้าแอปและการ์ด LINE
- ยังแสดงสิ่งที่เชื่อถือได้: แผนที่จุดที่ชื้น/แห้ง **เทียบกันเองในแปลง**, ภาพดาวเทียม, ประวัติ
- บอกตรง ๆ ว่ากำลังปรับปรุง และทำร่วมกับเกษตรจังหวัด — ไม่โทษข้อมูลดาวเทียม ไม่ใช้ศัพท์เทคนิค
- คำเตือนที่ส่งเข้า LINE (เมื่อความเสี่ยงเพิ่มขึ้น) **เสนอให้หยุดชั่วคราวด้วย** เพราะยังใช้วิธีเดิม — เตือนฝนจากพยากรณ์ยังส่งตามปกติ

## 2. ข้อความที่เสนอ

**ก. ป้ายระดับบนการ์ดแปลง / หัวการ์ดผลวิเคราะห์** (แทน "🔴 เสี่ยงสูง")
> 🛠️ **ระดับความเสี่ยง: กำลังปรับปรุง**

**ข. คำอธิบายใต้ป้าย (ตัวเล็ก 1–2 บรรทัด)**
> เรากำลังปรับวิธีประเมินให้แม่นขึ้นร่วมกับสำนักงานเกษตรจังหวัดราชบุรี
> ระหว่างนี้ดูจุดที่ชื้นหรือแห้งกว่าส่วนอื่นของแปลงได้จากแผนที่ด้านล่าง

**ค. เมื่อแตะ "ทำไม?" / ข้อมูลเพิ่มเติม**
> วิธีเดิมประเมินความชื้นของสวนที่มีต้นไม้หนาแน่นสูงเกินจริง ทำให้หลายแปลงขึ้น "เสี่ยงสูง" ทั้งที่ไม่ได้มีปัญหา
> วิธีใหม่จะเทียบความชื้นตอนนี้กับช่วงเดียวกันของปีก่อน ๆ ในแปลงของคุณเอง
> เจ้าหน้าที่เกษตรกำลังลงตรวจแปลงตัวอย่างเพื่อยืนยันผลก่อนเปิดใช้ (ประมาณ ___ สัปดาห์)
> ถ้าเห็นน้ำขังหรือต้นไม้มีอาการผิดปกติ ติดต่อเจ้าหน้าที่ได้ทันทีที่ปุ่ม "ติดต่อเจ้าหน้าที่"

**ง. คำอธิบายสีแผนที่ (แสดงคู่แผนที่เสมอ)**
> สีบนแผนที่เทียบกันเองภายในแปลงนี้: 🔴 แห้งกว่าส่วนอื่น · 🟢 กลาง ๆ · 🔵 ชื้นกว่าส่วนอื่น
> ไม่ได้แปลว่าแห้งหรือแฉะเกินไปจริง

**จ. ข้อความในสรุปรายสัปดาห์ (LINE)**
> 📋 สรุปแปลงรายสัปดาห์ · ระดับความเสี่ยงกำลังปรับปรุงร่วมกับเกษตรจังหวัด ดูจุดชื้น/แห้งในแปลงได้ในแอป

## 3. สิ่งที่จะเปลี่ยนเมื่ออนุมัติ (ประมาณ 1 วัน)
- LIFF: ป้ายแปลง/ผลวิเคราะห์/ประวัติ → ข้อความ ก–ง (สีขอบเขตแปลงเป็นสีกลางสีเดียว)
- การ์ด LINE (ปุ่ม "ตรวจสอบ", สรุปรายสัปดาห์): หัวการ์ดเป็นสีกลาง + ข้อความ ก, ข
- (ถ้าอนุมัติ) หยุดคำเตือน "ความเสี่ยงเพิ่มขึ้น" ชั่วคราว จนกว่าจะเปิดวิธีใหม่
- dashboard ผู้ดูแลยังเห็นระดับเดิม + วิธีใหม่คู่กัน (ไว้เทียบ)

## 4. คำถาม
1. ใช้ข้อความ ก–จ ตามนี้ หรือแก้ถ้อยคำ
2. ช่วงเวลาที่จะใส่ในข้อความ ค ("ประมาณ ___ สัปดาห์")
3. หยุดคำเตือน "ความเสี่ยงเพิ่มขึ้น" ชั่วคราวด้วยหรือไม่ (ผมแนะนำให้หยุด — ยังมาจากสูตรเดิม)
