# รายงาน Phase 3 — แจ้งเตือนผ่าน LINE OA + ติดตามระยะยาว (25 ต.ค. 2569)

ผู้อ่าน: เจ้าของโปรเจกต์ · การตัดสินใจ: [decisions.md](decisions.md)

## 1. สรุป

- **เตือนฝนแบบใหม่ใช้งานแล้ว** — บอกจุดเสี่ยงของแปลง + คำแนะนำจากตาราง และส่ง**น้อยลงมาก**จากเดิม (ไม่เพิ่มค่าใช้จ่าย)
- ผู้ใช้ตั้งเปิด/ปิด ความถี่ และสรุปรายสัปดาห์ได้เอง
- เทียบหน้าฝน/หน้าแล้งของแปลงเดียวกันย้อนหลัง 2 ปี (ปุ่ม "📅 เทียบฤดู")
- **ยังไม่ได้ขึ้นแพลน LINE OA หรือสมัครแหล่งพยากรณ์แบบเสียเงิน** — ทำเอกสารให้เลือก (ข้อ 3)
- test 377 รายการผ่าน · CI + smoke ผ่านทุกครั้ง · migration v20 (backup ก่อน)

## 2. เตือนฝนแบบใหม่

- **เตือนเมื่อ:** มีวันฝน ≥ 35 มม. ภายใน 3 วัน (≥ 90 มม. = ฝนหนักมาก ตามเกณฑ์กรมอุตุฯ → ความสำคัญสูง)
- **ข้อความ:** "พรุ่งนี้ฝนหนัก (~42 มม.) — แปลง A: มีจุดที่ชื้นกว่าส่วนอื่น 20 จุด เสี่ยงน้ำขังก่อน" + ทิศในแปลง
  + "ควรทำก่อนฝนมา" (ร่างจากตาราง heavy_rain_coming พร้อมป้ายร่าง) + หมายเหตุพืชอ่อนไหวน้ำขัง + ปุ่มเปิดแผนที่ + ที่มาข้อมูล
- **ไม่ซ้ำ:** ระดับเดิมไม่ส่งซ้ำใน 7 วันต่อแปลง · รวมทุกแปลงเป็น push เดียวต่อคน · ผู้ใช้เลือก "สูงสุดสัปดาห์ละครั้ง" ได้
- **ผลต่อจำนวนข้อความ:** ข้อมูลจริง 1 ปีของราชบุรี — กฎใหม่ ~2–5 รอบ/ปี/พื้นที่ (เกือบทั้งหมดใน ก.ย.)
  เทียบกฎเดิม (ฝน 7 วัน + สูตร SWAB เดิม) ที่วันนี้พยายามส่ง 19 แปลงในวันเดียว
- สวนยกร่อง: บอกเฉพาะฝน ไม่นับจุดชื้น

## 3. ต้องให้เจ้าของตัดสินใจ

1. **แหล่งพยากรณ์ฝน:** Open-Meteo ฟรีใช้ได้เฉพาะงานไม่ใช่เชิงพาณิชย์ — ถ้าโครงการเป็นเชิงพาณิชย์ต้องสมัคร (~$29/เดือน ตรวจราคาจริง)
   หรือขอ API จากกรมอุตุฯ · ระหว่างนี้ใช้ Open-Meteo ต่อ + ใส่ที่มาตามเงื่อนไข
2. **แพลน LINE OA:** ≤ 50 ผู้ใช้อยู่ Free ได้ · ขยายเกิน ~80–100 คน หรือก่อนหน้าฝนปีหน้า ควรขึ้น Basic ฿1,280/เดือน (ก่อน VAT)
3. **ข้อมูลระดับน้ำ/ความเค็ม:** ติดต่อ สสน. (ThaiWater) และชลประทานราชบุรี ([water-data-survey.md](water-data-survey.md))
4. ตรวจร่างคำแนะนำ "ฝนหนักกำลังมา" 3 ข้อ ในหน้า `/dashboard/recommendations.html`

## 4. ทดสอบบนมือถือ

1. "⚙️ ข้อมูลของฉัน → 🔔 การแจ้งเตือน" → ปิด/เปิดเตือนฝน เปลี่ยนเป็น "สูงสุดสัปดาห์ละครั้ง" → บันทึก → เปิดอีกครั้งค่าต้องคงอยู่
2. การ์ดแปลง → "📅 เทียบฤดู" → รอ ~20 วินาที → มีประโยคเทียบฤดู กราฟรายเดือน (จุดทึบ = หน้าฝน) และตารางรายฤดู
3. ข้อความเตือนฝนจริงจะได้รับเมื่อมีฝนหนักในพยากรณ์ **และโควตา LINE มีเหลือ** (รีเซ็ต 1 พ.ย.) — ตรวจว่าเห็นจุดเสี่ยง คำแนะนำ และกดปุ่มเปิดแผนที่ได้

## 5. ความเสี่ยง

- จุดเสี่ยงในข้อความมาจากตารางจุดของสแกนรายวันล่าสุด — แปลงที่ไม่มีขอบเขต/ยังไม่เคยสแกน จะบอกเฉพาะฝน
- การเทียบฤดูใช้ค่าเรดาร์ที่รวมทรงพุ่ม — ต้นไม้โตขึ้นหรือแก้ขอบเขตก็ทำให้ค่าเปลี่ยนได้ (มีหมายเหตุในหน้าจอ)
- กราฟแปลงหนึ่งที่ทดสอบมีค่าเพิ่มขึ้นชัดตั้งแต่ ก.ย. 2568 — อาจเป็นการเปลี่ยนจริงหรือการเปลี่ยนขอบเขต ควรดูภาคสนาม

## 6. ปักหมุดต้นไม้รายต้น (เพิ่ม 28 ต.ค. 2569 — spec 6.3 ตัวเลือก)

- การ์ดแปลง / แท็บเจ้าหน้าที่ → **"🌳 ต้นไม้รายต้น"** → ยืนชิดโคนต้น → "📍 ปักหมุดต้นที่ยืนอยู่" (ตั้งชื่อ/เลขต้น เลือกพืช)
- ต่อต้น: 🩺 อาการ (แท็กเดียวกับรูป) · 🌱 ใส่ปุ๋ย · 💨 พ่นยา (วันที่ + ชื่อปุ๋ย/ยา + ปริมาณ) · 📝 บันทึก · 📷 รูป → ประวัติเรียงล่าสุดก่อน
- "🧭 ต้นที่ใกล้ฉัน" เรียงต้นตามระยะจากตำแหน่งตอนนี้ · ไม่มีสัญญาณบันทึกไว้ในเครื่องแล้วส่งเอง
- ข้อจำกัด: GPS มือถือคลาดได้หลายเมตร ต้นไม้ห่างกันไม่กี่เมตร → **ชื่อ/เลขต้นคือตัวระบุหลัก** · ยังไม่แสดงหมุดบนแผนที่
- บันทึกปุ๋ย/ยาเป็นสิ่งที่ผู้ใช้ทำเอง ระบบไม่ได้แนะนำ · ต้องปักหมุดในแปลง (ยอมคลาดนอกขอบเขต ≤ 15 ม.)

ทดสอบบนมือถือ: ปักหมุด 2 ต้น → บันทึกอาการ 1 ครั้ง + ใส่ปุ๋ย 1 ครั้ง + รูป 1 รูป ให้ต้นแรก → เปิดต้นแรก เห็นครบ 3 รายการ
→ เปิดโหมดเครื่องบินแล้วบันทึก → "บันทึกไว้ในเครื่อง" → ปิดโหมดเครื่องบิน เปิดแอปใหม่ → บันทึกขึ้นในประวัติ
