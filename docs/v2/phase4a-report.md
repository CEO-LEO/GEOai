# รายงาน Phase 4a — จำแนกชนิดพืชจากภาพดาวเทียม (25 ต.ค. 2569)

ผู้อ่าน: เจ้าของโปรเจกต์ · การตัดสินใจ: [decisions.md](decisions.md) · ไลเซนส์: [license-review.md](license-review.md)

## 1. สรุป

- **ระบบจำแนกพืชสร้างครบและขึ้น production แล้ว แต่ยังไม่ทายให้ผู้ใช้เห็น** — ข้อมูลฝึก (แปลงที่ยืนยันชนิดพืช) ตอนนี้ = **0**
  จึงยังเทรนและวัดความแม่นจริงไม่ได้ ระบบถูกออกแบบให้ "ไม่ฝืนทาย" จนกว่าจะผ่านเกณฑ์
- ระหว่างนี้แอปมีปุ่ม **"🌱 ชนิดพืช"** ถามเจ้าของ/เจ้าหน้าที่ว่าแปลงปลูกอะไร → คำตอบกลายเป็นข้อมูลฝึก
- **เรื่องใหญ่ที่ต้องตัดสินใจ: ไลเซนส์ Earth Engine** — ถ้าโครงการเป็นงานที่มีค่าตอบแทนหรือบริการประจำให้หน่วยงานรัฐ
  ต้องใช้แพลน commercial (เริ่ม ~$500/เดือน) **กระทบทั้งแอป ไม่ใช่แค่ Phase 4** (รายละเอียดข้อ 4)
- test 406 รายการผ่าน · CI + smoke ผ่าน · migrate_v21 (backup ก่อน `backups/20261025_174221`)

| Definition of Done 4a | สถานะ |
|---|---|
| service จำแนกพืชทำงานกับแปลงในราชบุรี | 🟡 ทำงานครบวงจรบน production (สกัดข้อมูลดาวเทียมแปลงจริง 3–8 วินาที/แปลง) แต่ยังไม่มีโมเดล เพราะไม่มี label |
| รายงานผลประเมินแบบ spatial split ต่อพืช | 🟡 สคริปต์ประเมินพร้อม (แบ่งตามอำเภอ เทียบ random forest, F1 ต่อพืช, confusion matrix, รายอำเภอ) — ยังไม่มีข้อมูลให้ประเมิน |
| UI ทาย + ยืนยัน ทำงานในแอป | ✅ ใช่ / ไม่ใช่ / เลือกพืชอื่น / ไม่แน่ใจ (เจ้าของ + เจ้าหน้าที่) — ส่วนทายแสดงเมื่อเปิดโมเดล |
| label จากผู้ใช้ไหลกลับเข้าชุดฝึก | ✅ คำตอบ → ตาราง `crop_label_feedback` → ชุดฝึก (เฉพาะผู้ยินยอม) + นำเข้าทะเบียนเกษตรกรจาก CSV ได้ |
| รายงานเรื่องไลเซนส์ข้อมูล | ✅ [license-review.md](license-review.md) |

## 2. ระบบทำงานอย่างไร

1. **ข้อมูลดาวเทียมต่อแปลง** (คำนวณครั้งเดียว เก็บไว้ คำนวณใหม่เมื่อแก้ขอบเขต): ลายเซ็นภาพรายปีของ Google
   (Satellite Embedding 64 ค่า ปี 2025) + ความเขียวรายเดือน + เรดาร์รายเดือน + สัดส่วนต้นไม้ในขอบเขต
2. **ชุดฝึก:** แปลงที่มีชนิดพืช ของผู้ที่ยินยอมข้อ "ใช้ปรับปรุงระบบ" — เจ้าหน้าที่ยืนยันมีน้ำหนัก 3 เท่า ·
   ไม้ผลหลายชนิดในแปลงเดียว = "สวนผสม" · พืชที่มีน้อยกว่า 10 แปลงหรืออยู่อำเภอเดียว → รวมเป็น "อื่น ๆ"
3. **โมเดลเดียวหลายคลาส** (ไม่แยกโมเดลต่อพืช) → ผลทาย 3 อันดับ + ระดับความมั่นใจ (บนจอเป็นคำ ไม่แสดงตัวเลข)
   · ไม่มั่นใจพอ = "ระบบยังไม่แน่ใจ" · ทายเป็นไม้ผลแต่เห็นต้นไม้น้อย = "ไม่น่าใช่สวนไม้ผล"
4. **ประเมินแบบแบ่งตามอำเภอ** (แปลงอำเภอเดียวกันไม่อยู่ทั้งชุดฝึกและชุดทดสอบ) · **เปิดใช้ได้เมื่อ** ≥ 50 แปลง
   ≥ 3 อำเภอ macro-F1 ≥ 0.6 · ผลทายไม่เปลี่ยนชนิดพืชของแปลงจนกว่าผู้ใช้กดยืนยัน
5. แยกเป็นแพ็กเกจ `backend/crop_classifier/` ที่มี interface ของตัวเอง — รันใน server เดิม (ไม่มีค่าใช้จ่ายเพิ่ม)
   · เพิ่มแหล่งภาพใหม่ (THEOS-2/โดรน — Phase 4b) ได้โดยไม่แก้ส่วนอื่น

หน้าผู้ดูแล: `/dashboard/crop-model.html` — ดูจำนวนข้อมูลฝึก คำนวณข้อมูลดาวเทียม เทรน ดูรายงาน เปิด/ปิดโมเดล นำเข้าทะเบียน

## 3. ทำอย่างไรให้มีข้อมูลฝึกพอ (ประมาณ 50–100 แปลง ใน ≥ 3 อำเภอ ≥ 2 พืช × 10 แปลง)

1. **ทะเบียนเกษตรกร** (เร็วที่สุด): ขอจากสำนักงานเกษตรจังหวัด — แปลงพร้อมชนิดพืชและพิกัด ต้องทำข้อตกลงการใช้ข้อมูล (DPA) ก่อน
   แล้วนำเข้า CSV ที่หน้า crop-model (ระบบบังคับให้กรอกที่มาทางกฎหมาย)
2. ช่วงอบรม/ลงพื้นที่: ให้เจ้าหน้าที่กด "🌱 ยืนยันพืช" ในแปลงที่ไป (น้ำหนักสูงสุด)
3. ชวนเกษตรกรเปิดข้อ "ใช้รูปถ่ายและการยืนยันในแปลงเพื่อปรับปรุงระบบ" — ตอนนี้ยังไม่มีใครเปิด จึงยังไม่มีแปลงในชุดฝึก

## 4. ต้องให้เจ้าของตัดสินใจ

1. **ไลเซนส์ Earth Engine** (ข้อ 5 ใน [license-review.md](license-review.md)): โครงการมีค่าตอบแทน/บริการประจำหรือเป็นวิจัยนำร่อง ·
   Cloud project ลงทะเบียนแบบไหน · ถ้าต้องจ่าย เลือก Google for Startups / แพลน Basic / ให้หน่วยงานเป็นเจ้าของ project
2. **MERIT Hydro** (ใช้บอก "ที่ลุ่มต่ำ") ใช้เชิงพาณิชย์แบบปิดข้อมูลไม่ได้ — อนุมัติเปลี่ยนเป็น HAND จาก Copernicus DEM ก่อนเซ็นสัญญาหรือไม่
3. ขอทะเบียนเกษตรกรจากเกษตรจังหวัด + DPA
4. เมื่อมีโมเดลผ่านเกณฑ์ + ตอบข้อ 1 แล้ว → ตั้ง `CROP_GUESS_ENABLED=1` (Claude ทำให้ได้) แล้วกดเปิดใช้ในหน้า crop-model

## 5. ทดสอบบนมือถือ

1. การ์ดแปลง → **"🌱 ชนิดพืช"** → ถ้าแปลงมีพืชแล้ว: "แปลงนี้ปลูก ส้มโอ ใช่ไหม?" กด ✅ → ขึ้นข้อความขอบคุณ
2. แปลงที่ยังไม่มีพืช → เลือกพืช (หลายชนิดได้) → 💾 บันทึก → การ์ดแสดงพืชใหม่
3. เจ้าหน้าที่: แท็บเจ้าหน้าที่ → **"🌱 ยืนยันพืช"** ในแปลงของอำเภอตัวเอง → ใช้งานได้เหมือนข้อ 1–2
4. ⚙️ ข้อมูลของฉัน → ดาวน์โหลดข้อมูล → มีหัวข้อ `crop_answers`
5. หน้า `/dashboard/crop-model.html` → จำนวน "คำตอบยืนยันพืชทั้งหมด" เพิ่มขึ้น

## 6. ความเสี่ยง

- ลายเซ็นภาพปี 2025 ใช้ข้อมูลทั้งปี — สวนที่เพิ่งเปลี่ยนพืชหรือเพิ่งปลูกจะทายผิด (มีด่าน "ต้นไม้น้อย" ช่วยบางส่วน)
- ชุดข้อมูลจากทะเบียนเกษตรกรมักเป็นจุดเดียวต่อแปลง (ไม่มีขอบเขต) → ระบบใช้วงกลมรอบจุด อาจปนแปลงข้างเคียง
- เกณฑ์เปิดใช้และ "ไม่แน่ใจ" เป็นค่าทางสถิติ ปรับได้เมื่อมีผลประเมินจริง
- พืชที่ลายเซ็นคล้ายกัน (เช่น ฝรั่ง/ชมพู่ ทรงพุ่มเตี้ยคล้ายกัน) อาจแยกไม่ออกด้วยภาพ 10 ม. — จะรู้เมื่อมีผลประเมินต่อพืช
