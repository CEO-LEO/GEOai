# รายการตรวจทานสไลด์ v2 (`IAMROOT_AI_Geospatial_Durian_Intelligence_v2.pptx`)

ผู้อ่าน: เจ้าของโปรเจกต์ · ตรวจก่อนส่งทุน · รายการเดิม/ใหม่ทุกข้ออยู่ที่ [grant-v2-changes.md](grant-v2-changes.md)

ต้นฉบับเป็น **ภาพทั้งแผ่น** (ไม่มีข้อความจริงในไฟล์) จึงแก้ด้วยการวางกล่องสีทับ + กล่องข้อความใหม่ — ตาราง "วิธีแก้" ด้านล่างบอกว่าสไลด์ไหนทำแบบไหน
ภาพตัวอย่างที่ฉันดูมาจากการ export ของ PowerPoint COM บนเครื่องนี้ (ตัวจริงอาจเป็น WPS รุ่นที่รายงานเป็น 12.0) — **เปิดดูในโปรแกรมที่คุณจะใช้นำเสนอจริงอีกรอบ**

## 0. เรื่องที่ต้องรู้ก่อน (กระทบทุกสไลด์ที่วางทับ)

| เรื่อง | รายละเอียด | ข้อแนะนำ |
|---|---|---|

## 2. วิธีตรวจใน PowerPoint (5 นาที)

1. เปิดไฟล์ → View → **Slide Show** ทีละแผ่น ดูที่หน้าจอจริงที่จะใช้ฉาย
2. Home → Arrange → **Selection Pane** ดูว่ากล่องทับอยู่เหนือภาพ "Picture 2" (ภาพเดิม) ทุกแผ่น
3. สไลด์ 3 คลิกกราฟ → Chart Design → Edit Data เพื่อแก้ตัวเลข
4. ตรวจตัวสะกดไทยทุกกล่อง (ใช้ Review → Spelling) และตรวจให้ตัวเลขตรงกับ [grant-v2-changes.md](grant-v2-changes.md)
5. Export เป็น PDF แล้วเปิดดูอีกรอบ — ถ้าฟอนต์เพี้ยนใน PDF ให้ embed ฟอนต์
