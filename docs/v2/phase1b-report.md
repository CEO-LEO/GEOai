## 2. ประมาณการข้อความต่อเดือนใหม่

**สมมติฐาน** (จากข้อมูลจริง 15 ผู้ใช้ / 23 แปลง = 1.5 แปลงต่อคน):
- คำเตือนความเสี่ยง: ขึ้นเป็นสูงประมาณ 0.7 ครั้ง/แปลง/เดือนด้วยเกณฑ์ปัจจุบัน (จากข้อมูล 30 วัน) = **1.1 ครั้ง/คน/เดือน** · ถ้าอนุมัติวิธีใหม่ใน risk-level-review = 0.2/แปลง = 0.3/คน
- เตือนฝน (หน้าฝน กรณีแย่สุด ทุกแปลงเข้าเกณฑ์ตลอด): ไม่เกิน 1 ครั้ง/7 วัน/แปลง = **6.5 ครั้ง/คน/เดือน** · หน้าแล้งใกล้ 0
- สรุปรายสัปดาห์: 4.3 ครั้ง/เดือน/คนที่เปิด — ผู้ใช้เดิม 8 คนเปิดอยู่ + ผู้ใช้ใหม่สมมติเปิดเอง 10%
- กดตรวจในแอป / ปุ่มตรวจสอบ: **0** (ไม่ push แล้ว)

| ผู้ใช้ | ก่อน (สถิติจริง/ประมาณเดิม) | หลัง 1b — หน้าฝน (แย่สุด) | หลัง 1b — หน้าแล้ง | แพลนที่พอ |
|---|---|---|---|---|
| **15** (ตอนนี้) | ~1,400 | **~150** | ~50 | **Free (300) พอ** |
| **100** | ~12,900 | **~830** | ~180 | หน้าฝนเกิน Free → Basic ฿1,280 |
| **500** | ~64,500 | **~4,000** | ~800 | Basic ฿1,280 (15,000) |

ถ้าอนุมัติวิธีวัดความเสี่ยงใหม่ ลดเพิ่มอีกราว 10% (100 คน หน้าฝน ~750) — ตัวที่กินโควตาหลักเหลือแต่ **เตือนฝน**
ลดได้อีก (ถ้าต้องการ): รวมเตือนฝนของทุกแปลงของผู้ใช้คนเดียวเป็น push เดียว → 100 คน หน้าฝน ~610 (~530 ถ้าใช้วิธีวัดความเสี่ยงใหม่ด้วย)

**ต้องรัน `migrate_v13` หลัง deploy 1b** — ถ้ายังไม่รัน การกันเตือนฝนซ้ำจะไม่ทำงาน (เตือนฝนกลับไปเกือบทุกวัน ~10/แปลง/เดือน)

## 3. พฤติกรรมที่เปลี่ยน (แจ้งตามกติกา)

1. กดตรวจแปลงในแอปแล้ว **ไม่มีการ์ดเด้งในแชท** — ดูผลในแอป หรือกด "ตรวจสอบ" ใน Rich Menu
2. แปลงที่เป็น "สูง" ต่อเนื่องจะได้คำเตือน **ครั้งเดียว** ตอนขึ้นเป็นสูง (เดิมทุกวัน + escalation)
3. ผู้ใช้ 8 คนที่เปิดสรุปไว้ จะได้สรุป **สัปดาห์ละครั้ง** (วันจันทร์) แทนทุกวัน
4. ปุ่ม "ตรวจสอบ" ตอบช้าลงได้ถึง ~20 วินาทีเมื่อต้องสร้างรูป (มีจุด "กำลังพิมพ์" ระหว่างรอ) และแสดงรูปไม่เกิน 3 แปลง
5. **หลัง deploy 1b, GitHub Actions จะล้มทุกชั่วโมงช่วง 05–10 น. และส่งอีเมลจนกว่าโควตาจะกลับมา (1 พ.ย.)** เพราะตอนนี้โควตาหมดจริง — เป็นพฤติกรรมที่ตั้งใจ

## 6. คำถาม
1. **escalation:** เลิกส่งซ้ำทุกวันแล้วตามที่สั่ง — ต้องการ "เตือนซ้ำครั้งเดียว" ถ้ายังสูงต่อเนื่องเกิน 7 วันไหม (ค่าเริ่มต้น: ไม่)

3. ต้องการให้รวมเตือนฝนหลายแปลงเป็น push เดียวต่อคนด้วยไหม (ลดหน้าฝนได้อีก ~25%)
4. อนุมัติวิธีวัดความเสี่ยงใหม่ใน [risk-level-review.md](risk-level-review.md) หรือไม่
