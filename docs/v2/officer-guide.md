# คู่มือใช้แอป IAM ROOT สำหรับเจ้าหน้าที่เกษตร (ฉบับ 28 ต.ค. 2569)

เปิดแอปจากเมนูในแชท LINE ของ IAM ROOT · ใช้บนมือถือ

## 0. เปิดสิทธิ์เจ้าหน้าที่

1. กดลิงก์รหัสเชิญที่ได้จากผู้ดูแลระบบ (เปิดใน LINE) → ขึ้น "✅ คุณเป็นเจ้าหน้าที่แล้ว · อ.…"
2. ครั้งแรกแอปจะให้อ่านและยอมรับนโยบายความเป็นส่วนตัว
3. มีแท็บใหม่ **"👩‍🌾 พื้นที่ของฉัน"** — เห็นแปลงที่คุณวาดเอง และแปลงในอำเภอที่รับผิดชอบ
   **เฉพาะของเกษตรกรที่ยินยอมแบ่งปันกับเจ้าหน้าที่** · ทุกครั้งที่เปิดดูแปลงของคนอื่นถูกบันทึก และเจ้าของแปลงดูได้

## 1. เพิ่มแปลง

1. แท็บ **"➕ เพิ่มแปลงใหม่"** → ซูมแผนที่ให้เห็นแนวรั้ว/คูน้ำ
2. กด **"🔷 วาดขอบเขต"** แล้วจิ้มตามมุมสวนทีละจุด (อย่างน้อย 3 จุด) → **"✅ จบการวาด"**
   วาดเฉพาะส่วนที่เป็นสวน ไม่รวมบ้าน ถนน บ่อ — พลาดจุดไหนกด "↩️ ย้อนกลับ"
3. กด **"🔍 ตรวจสอบแปลงนี้"** → กรอกชื่อแปลง, เลือก **พืช** (หลายชนิดได้), เลือก **ลักษณะสวน**
   (แปลงเรียบ / สวนยกร่อง / ยกแปลงผัก)
4. ถ้าขอบเขตมีบ้าน/ถนนปน หรือเล็กมาก แอปจะเตือน — แก้ได้ด้วย "✏️ วาดใหม่" หรือกด "บันทึกตามนี้"
5. รอ 20–40 วินาที แผนที่ความชื้นในแปลงจะขึ้น

## 2. อ่านแผนที่

- **สีเทียบกันเองภายในแปลงนี้:** น้ำเงิน = ชื้นกว่าส่วนอื่น, เขียว = กลาง ๆ, แดง = แห้งกว่าส่วนอื่น
  — **ไม่ได้บอกว่าแห้งหรือแฉะเกินไปจริง** · 1 ช่อง ≈ 10×10 เมตร
- ประโยคสรุปเหนือแถบสีบอกจำนวนจุดและทิศในแปลง เช่น "จุดที่แห้งกว่าส่วนอื่น 23 จุด ส่วนใหญ่อยู่มุมเหนือตะวันตกของแปลง"
- ▲ ลูกศร = ทิศที่น้ำไหลตามความสูงต่ำของพื้นที่ · 🟣 วงม่วง = จุดที่น้ำจากรอบข้างไหลมารวม
  (ใช้ได้กับพื้นที่ที่มีความลาด — พื้นที่ราบมากจะไม่มีลูกศร)
- **สวนยกร่อง:** แผนที่ไม่แสดงลูกศร วงม่วง และไม่เตือนน้ำขัง เพราะน้ำในร่องทำให้ภาพดาวเทียมเห็นเป็นจุดชื้น
  และภาพละเอียด 10 เมตรยังแยกร่องกับสันร่องไม่ได้ — ดูได้ว่าส่วนไหนแห้งกว่าส่วนอื่น
- **แตะจุดสี** → เห็นว่าจุดนั้นเป็นปัญหาอะไร เหตุผล และวิธีดูแล

## 3. คำแนะนำ

- ปุ่ม **"💡 คำแนะนำ"** บนการ์ดแปลง: ภาพรวมทั้งแปลง (เช่น "ชื้นกว่าปกติของช่วงเดียวกันในปีก่อน ๆ", "แห้งกว่าปกติ")
- ทุกข้อมีป้าย **"ร่าง — รอเจ้าหน้าที่เกษตรตรวจ"** หรือ **"ตรวจแล้วโดย …"**
  คำแนะนำทั้งหมดยังเป็นร่าง — ไฟล์ให้ตรวจ: [recommendations-for-review.xlsx](recommendations-for-review.xlsx)
- ระดับความเสี่ยง (สูง/ปานกลาง/ปกติ) **อยู่ระหว่างปรับปรุง** ร่วมกับสำนักงานเกษตรจังหวัด จึงยังไม่แสดง

## 4. แก้แปลงเดิม

การ์ดแปลง → **"✏️ แก้ไข"**:
- เปลี่ยนชื่อ / พืช / ลักษณะสวน แล้วกด "💾 บันทึก"
- **"วาดขอบเขตใหม่"** — เส้นจางคือขอบเขตเดิม วาดใหม่แล้วกด "💾 บันทึกขอบเขตใหม่" (ประวัติการตรวจยังอยู่)
- **"รวมประวัติจากแปลงที่ซ้ำกัน"** — ถ้าสวนเดียวกันถูกวาดไว้หลายแปลง เลือกแปลงเดิมเพื่อย้ายประวัติมา
  แปลงเดิมจะถูกซ่อน (ข้อมูลไม่ถูกลบ)
- ถ้าการ์ดมีแถบ "ℹ️ ผลของแปลงนี้อาจยังไม่ตรงกับสวนทั้งหมด" ให้กด "วาดขอบเขตใหม่" ที่แถบนั้น

## 5. แชร์รายงาน

การ์ดแปลง → **"📤 แชร์ / PDF"** (รอ 20–40 วินาที):
- **"📄 เปิดรายงาน PDF"** — แผนที่ + สรุป + สิ่งที่ควรทำ (ลิงก์ใช้ได้ 7 วัน ไม่มีพิกัดแปลงในรายงาน)
- **"💬 แชร์ให้เพื่อนใน LINE"** — ส่งการ์ดสรุปให้เพื่อน/กลุ่ม (ปุ่มนี้ขึ้นเมื่อผู้ดูแลระบบเปิดใช้ใน LINE แล้ว)

## 6. รูปถ่ายในแปลง

การ์ดแปลง → **"📷 รูป"** → ถ่ายรูป/เลือกรูป → เลือกสิ่งที่เห็น (น้ำขัง ใบเหลือง แมลง/โรคพืช ฯลฯ) → "💾 บันทึกรูป"
- แอปใช้ตำแหน่งที่บันทึกในรูป ถ้าไม่มีกด "ใช้ตำแหน่งมือถือตอนนี้" · แตะจุดบนแผนที่แล้วกด "📷 แนบรูปจุดนี้" ก็ได้
- **ไม่มีสัญญาณก็ถ่ายได้** — รูปเก็บในเครื่องแล้วส่งเองเมื่อมีสัญญาณ · ระบบลบข้อมูลแฝงในรูป (EXIF) ก่อนเก็บ

## 7. ยืนยันในแปลงจริง (สำคัญ — ใช้วัดว่าระบบแม่นแค่ไหน)

แตะจุดสีบนแผนที่ หรือดูคำแนะนำของแปลง → **"ไปดูที่จุดนี้แล้ว เป็นแบบนี้จริงไหม?"** → ✅ จริง / ❌ ไม่จริง / 🤔 ไม่แน่ใจ
- ตอบหลังเดินไปดูจริงเท่านั้น · ไม่แน่ใจให้กด "ไม่แน่ใจ" ดีกว่าเดา

## 8. เทียบหน้าฝน / หน้าแล้ง

การ์ดแปลง → **"📅 เทียบฤดู"** (รอ 10–30 วินาที) → ประโยคเทียบกับปีก่อน เช่น "หน้าฝน 2569 ชื้นกว่าหน้าฝน 2568"
+ กราฟรายเดือน (จุดทึบ = หน้าฝน) · เทียบกับแปลงนี้เองเท่านั้น ต้นไม้โตหรือแก้ขอบเขตก็ทำให้ค่าเปลี่ยนได้

## 9. ชนิดพืช และสำรวจพืชภาคสนาม (ช่วยสอนระบบทายชนิดพืช)

- แปลงในรายการ → **"🌱 ยืนยันพืช"** → ใช่ / เลือกพืชที่ปลูกจริง — คำยืนยันของเจ้าหน้าที่มีน้ำหนักมากที่สุด
- แท็บ "👩‍🌾 พื้นที่ของฉัน" → **"📍 สำรวจจุดนี้"** — ใช้กับสวนที่ยังไม่มีในระบบ:
  1. ยืนใน**แปลงเดียว** ห่างขอบแปลงอย่างน้อย 20 เมตร
  2. รอจนขึ้น "✅ ตำแหน่งแม่นพอแล้ว" (ถ้าไม่ขึ้น ออกมาที่โล่งใต้ฟ้า)
  3. เลือกพืชที่เห็น → **ถามเจ้าของแปลงก่อน** แล้วติ๊ก "เจ้าของแปลงอนุญาต…" → บันทึก
  - ไม่ต้องมีบัญชีของเกษตรกร ไม่บันทึกชื่อเจ้าของ · ไม่มีสัญญาณก็บันทึกได้ ส่งเองทีหลัง
  - ลบจุดที่บันทึกผิดได้ที่ "จุดล่าสุดของฉัน"
- เป้าหมายรอบแรก: **พืชละ 10 จุดขึ้นไป ใน 2–3 อำเภอ** (มะพร้าวน้ำหอม ฝรั่ง ชมพู่ องุ่น ส้มโอ ทุเรียน)
- ระบบ**ยังไม่ทายชนิดพืช**ให้ผู้ใช้ จนกว่าจะมีข้อมูลพอและวัดความแม่นได้

## 10. ต้นไม้รายต้น

การ์ดแปลง → **"🌳 ต้นไม้รายต้น"**
1. ยืนชิดโคนต้น → **"📍 ปักหมุดต้นที่ยืนอยู่"** → ตั้งชื่อ/เลขต้นให้ตรงกับป้ายที่ต้น (ระบบตั้ง "ต้นที่ N" ให้)
2. แตะต้นในรายการ → บันทึก 🩺 อาการ · 🌱 ใส่ปุ๋ย · 💨 พ่นยา (วันที่ ชื่อปุ๋ย/ยา ปริมาณ) · 📝 บันทึก · 📷 รูป
3. กลับมาดูครั้งหน้า: **"🧭 ต้นที่ใกล้ฉัน"** เรียงต้นจากใกล้ไปไกล
- GPS มือถือคลาดได้หลายเมตร — ใช้**ชื่อ/เลขต้น**เป็นหลัก · บันทึกปุ๋ย/ยาเป็นข้อมูลที่ผู้ใช้จดเอง ระบบไม่ได้แนะนำ

## 11. แนะนำเกษตรกรเรื่องการตั้งค่า

เมนู **"⚙️ ข้อมูลของฉัน"**:
- **🔔 การแจ้งเตือน** — เปิด/ปิดเตือนฝนหนัก (เตือนเมื่อพยากรณ์มีฝน ≥ 35 มม. ใน 3 วัน พร้อมบอกจุดเสี่ยงในแปลง)
  และเลือก "สูงสุดสัปดาห์ละครั้ง" ได้
- **👁️ ใครเปิดดูแปลงของฉัน** · **📥 ดาวน์โหลดข้อมูล** · เปลี่ยนความยินยอม · ขอลบข้อมูล
- การแบ่งปันแปลงกับเจ้าหน้าที่ และการใช้คำตอบ/รูปสอนระบบ **เป็นทางเลือกของเกษตรกร** — ห้ามกดแทนหรือบังคับ

## 12. ข้อควรระวัง

- ข้อมูลจากดาวเทียมใช้ **ประกอบการตัดสินใจ** — ควรตรวจในแปลงจริงทุกครั้ง
- ตรวจ/ส่งพิกัดแปลงของเกษตรกรได้เฉพาะเมื่อ **เจ้าของยินยอมแล้ว** หรือเป็นแปลงที่เจ้าหน้าที่เพิ่มเอง
- สำรวจพืชหรือปักหมุดในสวนของใคร **ต้องได้รับอนุญาตจากเจ้าของก่อนทุกครั้ง**
- ห้ามส่งต่อรูป/พิกัดแปลงของเกษตรกรออกนอกแอป
- ถ้าเห็นอะไรไม่ตรงกับในสวน กด "❌ ไม่จริง" หรือแจ้งผู้ดูแลระบบ — ช่วยให้ปรับเกณฑ์ได้แม่นขึ้น
