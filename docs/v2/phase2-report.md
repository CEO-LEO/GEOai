## 3. ผลกระทบต่อผู้ใช้เดิม

- เปิดแอปครั้งถัดไปจะเห็น "ก่อนใช้งาน IAM ROOT" — ต้องกดยอมรับก่อนตรวจแปลงได้ (ดู/ลบข้อมูลได้แม้ไม่ยอมรับ)
- สแกนรายวัน/เตือนฝน/ปุ่มในแชท LINE ทำงานต่อเหมือนเดิม
- เจ้าหน้าที่จะยังไม่เห็นแปลงเกษตรกรคนใดจนกว่าเกษตรกรเลือก "แบ่งปันกับเจ้าหน้าที่" เอง

## 4. ทดสอบบนมือถือ (เปิดจากเมนูในแชท LINE)

1. เปิดแอป → เห็นหน้า "ก่อนใช้งาน IAM ROOT" → ติ๊ก "แบ่งปันกับเจ้าหน้าที่" → ยอมรับ → ใช้งานต่อได้
2. ปุ่ม "⚙️ ข้อมูลของฉัน" → ดาวน์โหลดข้อมูล / ใครเปิดดูแปลง / ขอลบแล้ว**ยกเลิกคำขอ** (แปลงต้องกลับมาครบ)
3. หน้า admin `/dashboard/users.html` → สร้างรหัสเชิญ (อ.เมืองราชบุรี) → เปิดลิงก์ในมือถืออีกเครื่อง → ได้แท็บ "👩‍🌾 พื้นที่ของฉัน"
4. แท็บพื้นที่ของฉัน: เห็นแปลงของข้อ 1 (ถ้าอยู่ อ.เมืองราชบุรี) → แผนที่/ตรวจ/คำแนะนำ/รายงานใช้ได้ · ข้อ 2 "ใครเปิดดูแปลง" ต้องเห็นรายการเจ้าหน้าที่
5. "📷 รูป" → ถ่ายรูปในสวน (เปิด GPS ในกล้อง) → เห็น "ใช้ตำแหน่งที่บันทึกในรูป" → แท็ก → บันทึก → รูปขึ้นในรายการ
6. ปิดเน็ต (โหมดเครื่องบิน) → แนบรูป → เห็น "รอส่ง 1 รูป" → เปิดเน็ต → ส่งเองภายในไม่กี่วินาที / ปิดแล้วเปิดแอปใหม่ก็ส่ง
7. แตะจุดสีบนแผนที่ → ปุ่ม จริง/ไม่จริง/ไม่แน่ใจ + "แนบรูปจุดนี้" ใช้ได้ · ปุ่ม 💡 คำแนะนำ มีปุ่มยืนยันระดับแปลง
8. หน้า admin `/dashboard/province.html` → ตัวเลขรายอำเภอ แผนที่ ไฟล์ส่งหน่วยงานเปิดใน Excel ได้ (ภาษาไทยไม่เพี้ยน)

## 5. ความเสี่ยง / สิ่งที่ค้าง

- นโยบายความเป็นส่วนตัวระบุผู้ควบคุมข้อมูลว่า "ทีมพัฒนา IAM ROOT" — ควรใส่ชื่อนิติบุคคล/ช่องทางทางการ และให้ผู้รู้ PDPA ตรวจ
  (แก้ `liff/privacy.html` + เปลี่ยน `PRIVACY_VERSION` ใน `backend/privacy.py` แล้วทุกคนจะถูกถามใหม่)
- พื้นที่เจ้าหน้าที่เป็นระดับอำเภอ (ไม่มีขอบเขตตำบลใน Earth Engine) — ถ้าได้ไฟล์ขอบเขตตำบลจากหน่วยงาน เพิ่มได้
- แปลงที่เจ้าหน้าที่วาดแทน ยังเป็นของเจ้าหน้าที่ (มีช่องชื่อเกษตรกร) — การโอนให้เกษตรกรยังไม่มี
- แดชบอร์ดจังหวัดดึงสถานะทีละแปลง (เร็วพอสำหรับหลักร้อยแปลง) — ถ้าเกินพันแปลงต้องทำตารางสรุปล่วงหน้า
- สถิติการใช้งานเริ่มนับ 25 ต.ค. 2569 (ก่อนหน้านั้นไม่มีข้อมูล)
- ถ้า LINE OA เปิด shareTargetPicker แล้ว ปุ่มแชร์จะขึ้นเอง

## 6. ต้องให้เจ้าของตัดสินใจ / ทำ

1. ตรวจถ้อยคำนโยบาย + ใส่ชื่อผู้ควบคุมข้อมูล (ข้อ 5)
2. ข้อตกลงการใช้ข้อมูลกับสำนักงานเกษตรจังหวัด ก่อนเชิญเจ้าหน้าที่เข้าระบบ ([data-governance.md](../data-governance.md) ข้อ 10)
3. สร้างรหัสเชิญให้เจ้าหน้าที่ที่จะลงพื้นที่ (หน้า `/dashboard/users.html`)
4. ระยะเวลาเก็บ audit log / สถิติการใช้งาน
5. งานค้างจาก Phase 1 ยังอยู่ (ลบ/สร้าง RENDER_API_KEY ใหม่, ลบ `backend/.env.bak-*`, เปิด shareTargetPicker ฯลฯ — [final-report.md](final-report.md) ข้อ 6)
