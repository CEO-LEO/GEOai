# ข้อความส่งเจ้าหน้าที่เกษตรจังหวัด (LINE) — ขอให้ตรวจคำแนะนำสำหรับทุเรียน

คุณเป็นผู้ส่งเอง · แนบไฟล์ `docs/v2/recommendations-for-review.xlsx` · ข้อความสั้นพออ่านบนมือถือ (แก้ชื่อ/กำหนดส่งตามจริงก่อนส่ง)

## ฉบับหลัก (ส่งในแชท)

```
สวัสดีครับ พี่/คุณ ____ ผม ____ จากโครงการ IAM ROOT (ระบบดูภาพดาวเทียมบอกจุดชื้น/จุดน้ำขังในสวนทุเรียน ผ่าน LINE) 🌳

ขอรบกวนช่วยตรวจ "ข้อความแนะนำ" ที่ระบบจะแสดงให้เกษตรกรครับ ตอนนี้เป็นร่างทั้งหมด 17 ข้อ ยังไม่เปิดให้เกษตรกรเห็นว่าเป็นข้อที่ตรวจแล้วจนกว่าจะได้รับการตรวจจากเจ้าหน้าที่

📎 ไฟล์แนบ: ตาราง Excel (ไม่มีข้อมูลส่วนตัวของเกษตรกร)
วิธีตรวจ (ประมาณ 20–30 นาที):
1) ดูคอลัมน์ "วิธีแก้" ของแต่ละข้อ
2) ช่อง "ผลตรวจ" เลือก ใช้ได้ / แก้ตามความเห็น / ตัดออก
3) ถ้าแก้ เขียนข้อความที่เหมาะในช่อง "ความเห็น"
4) ท้ายไฟล์มีชีต "คำถามสำหรับเจ้าหน้าที่" 7 ข้อ ตอบเท่าที่สะดวกครับ

จุดที่ผมอยากได้ความเห็นมากที่สุด: คำแนะนำเรื่องการให้น้ำ/ระบายน้ำ เหมาะกับทุเรียนหรือไม่ และเหมาะกับสวนยกร่องหรือไม่
ผมเอาชื่อสารเคมีและปริมาณปุ๋ยออกหมดแล้ว จะไม่ใส่เองจนกว่าเจ้าหน้าที่ตรวจ

รบกวนส่งไฟล์คืนภายใน ____ (ถ้าติดขัดบอกได้เลยครับ) ขอบคุณมากครับ 🙏
```

## ฉบับสั้น (ถ้าต้องการข้อความเดียว)

```
สวัสดีครับ ขอรบกวนตรวจข้อความแนะนำสำหรับสวนทุเรียนของระบบ IAM ROOT (17 ข้อ ไฟล์ Excel แนบ) เลือก ใช้ได้ / แก้ / ตัดออก ในช่อง "ผลตรวจ" แล้วส่งคืนภายใน ____ ครับ ใช้เวลาราว 20–30 นาที ไม่มีข้อมูลส่วนตัวของเกษตรกรในไฟล์ ขอบคุณครับ 🙏
```

## ข้อความตามหลังเมื่อเจ้าหน้าที่ตอบรับ (ถ้าต้องการ)

```
ขอบคุณมากครับ 🙏 ผมจะปรับตามความเห็นและให้เจ้าหน้าที่ยืนยันอีกรอบก่อนเปิดใช้ในแอปครับ
อีกเรื่องครับ: ช่วงต่อไปมีเกษตรกรอาสาทดสอบในแอป (ตอบว่าจุดที่ระบบชี้ น้ำขังจริงไหม) ถ้าสะดวกอยากให้เจ้าหน้าที่ช่วยตรวจซ้ำบางจุดในสวน ผมจะส่งรายการแปลงที่เจ้าของยินยอมให้ภายหลังครับ
```

## ก่อนกดส่ง ตรวจ 3 อย่าง
1. เปิดไฟล์ Excel ดูว่าไม่มีชื่อ/พิกัดเกษตรกร (ไฟล์นี้สร้างจากตารางคำแนะนำ ไม่มีข้อมูลส่วนบุคคล)
2. ใส่กำหนดส่งคืนที่ช่อง `____`
3. ถ้ามีข้อความเรื่องการเก็บเงิน/สิทธิ์ใช้งานที่ยังไม่ได้ตัดสินใจ อย่าใส่ในข้อความนี้ (ข้อความข้างต้นไม่มี)
