# ร่างคำขอข้อมูลแปลงจากทะเบียนเกษตรกร (สำหรับสอนระบบทายชนิดพืช)

ผู้อ่าน: เจ้าของโปรเจกต์ (ใช้เป็นร่างหนังสือ/อีเมลถึงสำนักงานเกษตรจังหวัดราชบุรี) · **ร่าง — ยังไม่ได้ส่ง**
· ควรให้ผู้รู้ด้าน PDPA ของหน่วยงานตรวจก่อนส่ง · ไฟล์ตัวอย่าง: [templates/reference_labels_template.csv](templates/reference_labels_template.csv)

---

**เรื่อง** ขอความอนุเคราะห์ข้อมูลตำแหน่งและชนิดพืชของแปลงเกษตร เพื่อพัฒนาระบบทายชนิดพืชจากภาพถ่ายดาวเทียม

**เรียน** เกษตรจังหวัดราชบุรี

ด้วย [ชื่อหน่วยงาน/ทีมผู้พัฒนา IAM ROOT] กำลังพัฒนาความสามารถให้แอป IAM ROOT ทายว่าแปลงหนึ่ง ๆ
น่าจะปลูกพืชอะไรจากภาพถ่ายดาวเทียม เพื่อช่วยเจ้าหน้าที่ตรวจข้อมูลแปลงและลดงานบันทึกของเกษตรกร
ระบบต้องมีตัวอย่างแปลงที่ทราบชนิดพืชแน่นอนจำนวนหนึ่งเพื่อเรียนรู้และวัดความแม่นยำก่อนเปิดใช้งาน

จึงขอความอนุเคราะห์ข้อมูลจากทะเบียนเกษตรกร ดังนี้

| ข้อมูล | รายละเอียด |
|---|---|
| ขอบเขต | อำเภอในจังหวัดราชบุรีอย่างน้อย 3 อำเภอ (เช่น ดำเนินสะดวก บางแพ โพธาราม) |
| พืช | มะพร้าวน้ำหอม ฝรั่ง ชมพู่ องุ่น ส้มโอ ทุเรียน (พืชละอย่างน้อย 10 แปลง ยิ่งมากยิ่งดี) |
| ต่อแปลง | รหัสอ้างอิงแปลง (ไม่ต้องใช้ชื่อ/เลขบัตร) · ชนิดพืช · พิกัดจุดกลางแปลง (ละติจูด/ลองจิจูด) · อำเภอ |
| ไม่ต้องการ | ชื่อ-สกุล เลขบัตรประชาชน ที่อยู่ เบอร์โทร ข้อมูลการเงิน |

**การคุ้มครองข้อมูล**
- ใช้เพื่อสอนและวัดผลระบบทายชนิดพืชเท่านั้น ไม่แสดงในแอปของผู้ใช้คนใด และไม่เผยแพร่พิกัดต่อสาธารณะ
- เก็บในฐานข้อมูลที่เข้าถึงได้เฉพาะระบบหลังบ้าน (ปิดสิทธิ์การเข้าถึงโดยตรง) ที่ตั้งเซิร์ฟเวอร์: ญี่ปุ่น (Supabase)
- ทุกการนำเข้าบันทึกที่มาทางกฎหมายของข้อมูลและผู้นำเข้า · ลบได้ทั้งชุดเมื่อหน่วยงานแจ้ง
- ผลประเมินความแม่นยำรายงานกลับหน่วยงานเป็นตัวเลขรวมรายพืช/รายอำเภอ
- ยินดีจัดทำข้อตกลงการประมวลผลข้อมูล (DPA) ตามแบบของหน่วยงานก่อนรับข้อมูล

**รูปแบบไฟล์ที่สะดวกที่สุด:** Excel หรือ CSV ตามตัวอย่างแนบ (คอลัมน์ `ref, crop, lat, lng, district`)

## สำหรับเจ้าของ: หลังได้ไฟล์

1. ตรวจว่าไม่มีชื่อ/เลขบัตรในไฟล์ (ถ้ามีให้ลบคอลัมน์ออกก่อน) · บันทึกเลขที่/วันที่ของ DPA
2. หน้า `/dashboard/crop-model.html` → "นำเข้าแปลงอ้างอิง" → ชื่อชุดข้อมูล เช่น `farmer_registry_2569`
   ที่มาทางกฎหมาย เช่น "DPA กับ สนง.เกษตรจังหวัดราชบุรี เลขที่ … ลงวันที่ …" → เลือกไฟล์ → นำเข้า
3. กด "คำนวณข้อมูลดาวเทียม" จนหมด → "ประเมิน + เทรน" → ดูรายงาน
4. ถ้าหน่วยงานขอให้ลบ: แจ้ง Claude ให้ลบแถว `reference_labels` ของชุดนั้น (feature ที่คำนวณไว้ลบตามอัตโนมัติ)
