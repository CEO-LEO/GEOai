นโยบายความเป็นส่วนตัว IAM ROOT

ฉบับวันที่ 25 ตุลาคม 2569 · บริการตรวจแปลงสวนจากภาพดาวเทียมผ่าน LINE

1. ใครเป็นผู้ดูแลข้อมูล

ทีมพัฒนา IAM ROOT เป็นผู้ควบคุมข้อมูลส่วนบุคคลของบริการนี้ ติดต่อได้ที่ปุ่ม "ติดต่อเจ้าหน้าที่" ในเมนูแชท LINE ของ IAM ROOT · บริการนี้ทดลองใช้ร่วมกับสำนักงานเกษตรจังหวัดราชบุรี

2. ข้อมูลที่เราเก็บ และใช้ทำอะไร

ข้อมูลใช้ทำอะไรฐานทางกฎหมาย
LINE userId และชื่อที่แสดงใน LINEยืนยันตัวตน ส่งข้อความที่คุณเลือกรับจำเป็นต่อการให้บริการ
ตำแหน่ง ขอบเขต ชื่อแปลง ชนิดพืช ประเภทสวนวิเคราะห์แปลงจากภาพดาวเทียม แสดงผลและคำแนะนำจำเป็นต่อการให้บริการ
ผลวิเคราะห์และประวัติการตรวจแสดงแนวโน้ม ทำรายงานให้คุณจำเป็นต่อการให้บริการ
สถิติการใช้งาน (เปิดแอป ตรวจแปลง ดูคำแนะนำ)ปรับปรุงระบบ และรายงานภาพรวมต่อหน่วยงานรัฐ โดยไม่ระบุตัวบุคคลประโยชน์โดยชอบด้วยกฎหมาย
รูปถ่ายที่คุณแนบ (พร้อมพิกัด/เวลาที่ถ่าย) และคำตอบ "จริง/ไม่จริง" ในแปลงบันทึกสภาพแปลง · ถ้าคุณยินยอม: ตรวจความแม่นยำและสอนระบบจำแนกพืชความยินยอม (สำหรับการปรับปรุงระบบ)
บันทึกการเข้าถึง (ใครเปิดดู/แก้แปลงของใคร เมื่อไร)ความปลอดภัยของข้อมูล และให้คุณตรวจสอบได้หน้าที่ตามกฎหมาย / ประโยชน์โดยชอบด้วยกฎหมาย

เราไม่เก็บเลขบัตรประชาชน เบอร์โทร ที่อยู่บ้าน หรือข้อมูลการเงิน

3. ใครเห็นข้อมูลของคุณ

  • คุณ — เห็นและแก้แปลงของตัวเองทั้งหมด
  • เจ้าหน้าที่เกษตรในอำเภอของแปลง — เฉพาะเมื่อคุณเลือก "แบ่งปันกับเจ้าหน้าที่" เพื่อช่วยแนะนำและตรวจในแปลง (ปิดได้ทุกเมื่อในเมนู "ข้อมูลของฉัน") · ทุกครั้งที่เจ้าหน้าที่เปิดดูถูกบันทึกไว้ และคุณดูได้
  • ผู้ดูแลระบบ — เข้าถึงได้เพื่อดูแลระบบและแก้ปัญหา ทุกครั้งถูกบันทึกไว้
  • หน่วยงานรัฐ — ได้เฉพาะตัวเลขภาพรวมรายอำเภอ (เช่น จำนวนแปลง พื้นที่ ชนิดพืช) ไม่มีชื่อหรือพิกัดของคุณ
  • รายงาน PDF / การ์ดที่คุณกดแชร์เอง ไปถึงผู้รับที่คุณเลือก (รายงานไม่มีพิกัดแปลง)

4. ผู้ให้บริการที่ช่วยประมวลผล (อาจอยู่นอกประเทศไทย)

  • Render — เซิร์ฟเวอร์ของแอป (สิงคโปร์)
  • Supabase — ฐานข้อมูลและที่เก็บรูป (ญี่ปุ่น)
  • Google Earth Engine — ประมวลผลภาพดาวเทียมจากตำแหน่งแปลง
  • LINE (LY Corporation) — ยืนยันตัวตนและส่งข้อความ

ผู้ให้บริการเหล่านี้ใช้ข้อมูลเพื่อให้บริการแก่เราเท่านั้น

5. เก็บนานแค่ไหน

  • ข้อมูลแปลงและผลวิเคราะห์ — ตลอดที่คุณใช้บริการ หรือจนกว่าคุณขอลบ
  • รูปแผนที่ที่ส่งเข้า LINE และรายงาน PDF — ลบอัตโนมัติหลัง 7 วัน
  • เมื่อคุณขอลบข้อมูล — ซ่อนแปลงและหยุดส่งข้อความทันที ยกเลิกคำขอได้ภายใน 30 วัน หลังจากนั้นลบถาวร (บันทึกการเข้าถึงเก็บต่อโดยไม่มีตัวตนของคุณ)

6. สิทธิ์ของคุณ

  • ดูและดาวน์โหลดข้อมูลของคุณ รวมถึงรายการว่าใครเคยเปิดดูแปลงของคุณ — เมนู "⚙️ ข้อมูลของฉัน" ในแอป
  • ขอลบข้อมูล และถอน/เปลี่ยนความยินยอมข้อที่ไม่บังคับได้ทุกเมื่อ — เมนูเดียวกัน
  • ขอแก้ไขข้อมูลแปลง — แก้เองได้ในแอป
  • ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.) ได้

7. การเปลี่ยนแปลงนโยบาย

ถ้าเปลี่ยนเนื้อหาที่มีผลต่อสิทธิ์ของคุณ แอปจะแจ้งและขอความยินยอมใหม่ก่อนใช้งานต่อ
